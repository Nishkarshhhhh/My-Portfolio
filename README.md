# Nishkarsh Varshney — Software Developer Portfolio

A production-quality developer portfolio website built with **Next.js 14 (App Router)**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Projects Showcased

1. **[Distributed Job Scheduler](https://github.com/Nishkarshhhhh/distributed-job-scheduler)** *(Flagship)*
   - Distributed job scheduling platform with REST APIs, CRON-based scheduling, job queues, retries, execution tracking, and worker coordination.
   - **Stack**: TypeScript, Node.js, Express, BullMQ, Redis, PostgreSQL, Prisma, Docker Compose.

2. **[Cartzilla](https://github.com/Nishkarshhhhh/Online-shopping-system)**
   - Full-stack e-commerce web platform with user authentication, product catalog, search, shopping cart workflows, order management, and role-based admin access.
   - **Stack**: PHP, MySQL, JavaScript, HTML, CSS, Bootstrap.

3. **Fake News Detection**
   - Natural Language Processing and machine learning classifier trained on 44,000+ articles to detect misinformation with ~98.6% prediction accuracy.
   - **Stack**: Python, NLP, Scikit-learn, Pandas.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18.17+ or v20+)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Nishkarshhhhh/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build
```bash
npm run build
npm run start
```
